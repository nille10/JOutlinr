# JOutlinr
![joutliner_logo.png](src/main/resources/images/joutliner_logo.png)  
JOutlinr ist ein Java-basierter Outliner zum hierarchischen Strukturieren von Informationen. Flexibel, erweiterbar und für jeden Anwendungsfall geeignet – vom Brainstorming bis zur Projektplanung.

# Ideen
Tree Struktur  
Keyboard Steuerung - verschieben der Nodes fehlt
Undo Redo Funktion - fertig
Columns  
Export/Import as JSON/XML
