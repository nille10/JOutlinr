# Ideen

## Tree Struktur
- JTree
- JTree.DropLocation für drag and drop

## Keyboard Steuerung-
- STRG-S Speichern
- STRG-Z Undo
- STRG-Y Redo
- ARROWS Navigieren in den Nodes
- STRG-ARROWS bewegen der Nodes
- SHIFT-Pfeiltasten
- DEL delete Node
- ENTER -> child Node
- RETURN <- parent Node
- (STRG-1-9 Root Node 1-9)

## Undo Redo Funktion
- Undo/Redo Stack
- Bei Undo die Einträge vom Stack nehmen und auf den Redo Stack legen
- Bei neuen Eingaben den Redo Stack leeren
- Texteingaben sollten zusammengefasst werden
